# Slo-Mo Mod

This is a mod for Lonely Mountains Downhill, allowing you to slow down gameplay and capture amazing cinematics.

## How to Install

Firstly, Lonley Mountains Downhill is a 64x game. Throughout the installation process you will need to be downloading the 64x versions.

### 1. Download Melon Loader
Go to https://melonwiki.xyz <br/>
Make sure you have the requirements - https://melonwiki.xyz/#/?id=requirements <br/>
Look under "Automated Installation" - https://melonwiki.xyz/#/?id=automated-installation <br/>
Download the installer for your platform (either windows or linux)

### 2. Installing Melon Loader
Run the Melon Loader installer <br/>
If LMD doesn't appear then select choose folder manually. <br/>
Your game folder can be found by going into steam library rigt clicking on the game, select "manage", then "browse local files" <br/>
Run the game once to check if Melon Loader has installed correctly (the original load after installing or updating Melon Loader can be rather slow so be patient) <br/>
As long as the Melon Loader splash screen appears, then you're installation is working fine. <br/>
If the game freezes on quit, then add `--quitfix` to the steam launch settings. They can be found by: in steam library, right clicking the game, selecting "properties", "general", "launch options". <br/>

### 3. Download and Install this Mod
Download the latest `SloMoMod.dll` from the releases section on this page. <br/>
Go to your game folder and paste the mod in the `Mods` folder. <br/>

### 4. Run the Game
Start the game as you normally would, watch for the mod name and version to appear during the Melon Loader start up to know if the mod has been loaded. Alternatively you can check the command panel which will also open, do **NOT** close this window while you are playing the game.
